# Учебные задания: Qt5 QPainter и QPalette

## О чем проект
Учебные примеры для изучения **Qt Framework** (C++):
- Рисование графических примитивов через `QPainter`
- Работа с палитрой цветов `QPalette`
- Обработка события перерисовки `paintEvent()`
- Динамическое размещение элементов относительно размеров окна

## Что внутри

| Файл | Задача |
|------|--------|
| `taks1.cpp` | Окно с цветной палитрой (желтый активный / зеленый неактивный) |
| `task2.cpp` | Горизонтальный ряд красных прямоугольников с отступами |
| `task4.cpp` | Диагональная цепочка квадратов |
| `widget.cpp` | Тестовое рисование одного прямоугольника |

## Как собрать

```bash
sudo apt install qt5-default qt5-qmake
qmake project.pro
make
